# STN-7 Problem Solving — Assignment 04

All 20 problems from the *STN-7 Problem Solving Assessment List* are solved in a single file: **`solution.js`**.

## How to run
```bash
node solution.js
```
This runs the built-in test cases (all examples from the problem list plus extra edge cases) and prints the pass/fail count.
